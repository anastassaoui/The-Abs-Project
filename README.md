# The Abs Project - Attendance Management System

A Flask-based web application for managing student attendance using temporary QR codes. This system allows teachers to generate time-limited codes and students to mark their attendance by entering these codes.

## Features

### For Students
- **User Registration & Login**: Secure account creation and authentication
- **Attendance Marking**: Mark attendance using temporary codes generated by teachers
- **Attendance History**: View personal attendance records with dates and timestamps
- **Time Restrictions**: Prevents multiple attendance submissions within 1-hour intervals

### For Teachers/Admins
- **Admin Dashboard**: Dedicated interface for teachers and administrators
- **Code Generation**: Generate temporary 7-character codes valid for 30 seconds
- **Student Management**: View all student attendance records
- **Attendance History**: Monitor attendance across all students

### Security Features
- **Password Hashing**: Uses PBKDF2-SHA256 for secure password storage
- **Session Management**: Flask sessions for user authentication
- **Code Expiration**: Temporary codes expire after 30 seconds
- **Duplicate Prevention**: Users cannot use the same code multiple times
- **Admin Protection**: Admin-only routes protected with authorization checks

## Technology Stack

### Backend
- **Flask** (3.0.2) - Web framework
- **PostgreSQL** - Database (with psycopg2 adapter)
- **Werkzeug** (3.0.1) - WSGI utilities and password hashing
- **Gunicorn** (21.2.0) - WSGI HTTP server for production

### Frontend
- **HTML/CSS** - User interface
- **Tailwind CSS** (3.4.10) - Utility-first CSS framework
- **PostCSS** - CSS processing
- **Vite** - Build tool for development

## Database Schema

### Users Table
- `id` - Primary key (serial)
- `firstname` - User's first name
- `lastname` - User's last name  
- `email` - Unique email address
- `password` - Hashed password
- `admin` - Boolean flag for admin privileges

### Presence Table
- `id` - Primary key (serial)
- `userid` - Foreign key to users table
- `date` - Date of attendance
- `scannedat` - Timestamp when code was scanned

### Temp_codes Table
- `id` - Primary key (serial)
- `code` - Generated temporary code
- `generated_at` - Timestamp of code generation

### Code_usage Table
- `id` - Primary key (serial)
- `code_id` - Foreign key to temp_codes table
- `user_id` - Foreign key to users table
- Unique constraint prevents duplicate code usage

## Installation & Setup

### Prerequisites
- Python 3.x
- Node.js and npm/yarn
- PostgreSQL database

### Backend Setup
1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd The-Abs-Project
   ```

2. Create a virtual environment:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # On Windows: .venv\Scripts\activate
   ```

3. Install Python dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Set up PostgreSQL database and update connection string in `database.py`

5. Initialize the database:
   ```bash
   python -c "from database import init_db; init_db()"
   ```

### Frontend Setup
1. Install Node.js dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```

2. Build CSS:
   ```bash
   npm run build
   ```

### Running the Application

#### Development
```bash
python app.py
```

#### Production
```bash
gunicorn app:app
```

The application will be available at `http://localhost:5000`

## Usage

### For Teachers
1. Sign up with admin privileges or have admin status assigned
2. Log in to access the teacher dashboard
3. Generate temporary codes for attendance
4. Monitor student attendance through the history page

### For Students
1. Sign up for a student account
2. Log in to access the student dashboard
3. Enter the temporary code provided by teacher to mark attendance
4. View attendance history on the personal history page
